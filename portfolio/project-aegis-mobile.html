Architecture

A Native Mobile Experience

Aegis Mobile is built using the Flutter (Dart) framework to serve as the counterpart to the Aegis React web app. It is tailored specifically for esports team and player management, offering full feature parity on the go.

The app relies on a clean architectural approach, strictly separating the UI screens, Riverpod state management, API service layers, and models. Real-time data is synced using socket_io_client, while persistent data is cached locally via Hive NoSQL storage and secured with flutter_secure_storage.

Core Implementations

  • ✦State Management: Powered entirely by flutter_riverpod for reactive UI updates.
  • ✦Networking: Fast and reliable API requests utilizing the dio and http packages.
  • ✦SSO Authentication: Seamless OAuth integration via google_sign_in.

Features

Esports Team Management

The app heavily focuses on comprehensive Team Management. Users can view detailed team profiles, check rosters, and manage private team permissions. Team captains have access to native modal bottom sheets to edit logos, send invites, and manage members.

The "My Teams" dashboard aggregates current teams and pending invitations, while a paginated search system allows users to seamlessly discover new players and organizations.

Media & Notifications

  • ✦Native Media Pickers: Upload team logos via native gallery pickers (image_cropper).
  • ✦Image Caching: All assets are optimized and cached via cached_network_image.
  • ✦Push Notifications: Full Firebase Cloud Messaging (FCM) integration for live alerts.

Aesthetics

Premium Dark Mode Design

The UI is designed with a premium esports aesthetic. The primary theme uses a very dark grey background (#09090B) with dark zinc cards, elevated by vibrant accents of cyan, purple, and blue.

Modern glassmorphic cards, gradient accents, and icon-based navigation provide a sleek, gaming-focused user experience.

Future Roadmap

  • ✦Social Expansion: "Follow Team" and "Share Team" functionality.
  • ✦UX Refinements: Pull-to-refresh on dashboards and backend-driven achievement syncing.

Aegis: esports management platform

Team recruitment, profile building, tournament registration and an organisation portal with real-time live chat, deployed on AWS.

Frontend Ecosystem

Web Client & Admin Dashboard

The Aegis platform features two distinct frontend portals built for high performance using React 19 and Vite. The main Web Client provides a seamless interface for players and tournament organizers, while the decoupled Admin Dashboard is tailored for platform moderators to oversee massive tournament brackets and user reports.

Both applications utilize Tailwind CSS v4 for utility-first styling and rely heavily on TanStack Query for robust API data fetching, caching, and state synchronization. Real-time integration is achieved via socket.io-client, reflecting live changes in chats, scores, and notifications without requiring page reloads.

Key Client Features

  • ✦Real-Time UI: WebSockets eliminate page reloads for live match state updates.
  • ✦Seamless SSO: @react-oauth/google integration for instantaneous onboarding.
  • ✦Admin Oversight: Dedicated dashboard to manage roles, support tickets, and resolve reports.

Core Architecture

Robust Backend Infrastructure

The core of Aegis is a RESTful API built on Node.js, Express.js, and MongoDB (Mongoose). It handles the full lifecycle of esports tournaments, team rosters, and real-time communication.

The live chat and match state systems are powered by Socket.IO integrated with a Redis adapter, allowing WebSockets to scale horizontally across multiple instances. Security is strictly enforced using JWT for stateless sessions, helmet for HTTP headers, and express-rate-limit.

Core Domain Modules

  • ✦Match Management: Tracks live match states and calculates phase standings automatically.
  • ✦LFP/LFT Recruitment: A swipe-based discovery system matching players to organizations.
  • ✦Fantasy Esports: Draft players, build rosters, and compete in fantasy leagues.

Automation

Automated Score Processing via OCR

To eliminate the most tedious part of esports management—manual data entry—Aegis includes a specialized microservice utilizing the AWS Rekognition SDK and Tesseract.js.

Organizers simply upload screenshots of end-of-match scoreboards. The OCR engine scans the images, extracts team names, placements, and eliminations, and automatically updates the tournament leaderboards.

Cloud Integrations

  • ✦AWS Rekognition: Drives the optical character recognition for scoreboards.
  • ✦Cloudinary: Handles scalable image and media asset storage.
  • ✦Firebase Admin SDK: Dispatches real-time push notifications.
  • ✦node-cron: Executes background tasks like bracket updates and matchmaking.
